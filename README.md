# Serein Day

一个简约的 Android 倒数日应用，采用**极简清冷**视觉体系（浅灰 / 银灰 / 黑白中性底色 + 每套一个高饱和点缀色，Material 3），交互向 Days Matter（倒数日）看齐：分类切换、大号天数、纯列表、极简模式。完整设计标注（色板 / 栅格 / 字号 / 动效）见 `docs/DESIGN.md`。

## 已实现（v1.4.0 · 极简清冷）

- **倒数本（Days Matter 式分类）**：首页标题下方横滑分类 chips（全部 / 各倒数本 / 管理）直接切换，选中主色填充、未选中描边；「管理倒数本」改为底部弹层，支持新建、重命名、删除（删除时事件移入首个剩余倒数本）
- **首页 Home**：iOS 大标题（倒数日 + 今日日期副标题）；置顶事件自动成为里程碑大卡（封面图 / 渐变、进度环入场动画、实时天数、最新小记摘要，置顶带徽标）；其余事件按「今天 / 未来 / 已过去」分组展示；极简滚动指示条；大号天数使用等宽数字（tnum）不跳动
- **排序方式**：底部弹层单选（按剩余天数 / 按目标日期 / 按添加时间），置顶始终最前
- **新建/编辑**：中文标题（新建倒数日 / 编辑倒数日）+ 右上角保存；名称（24 字限制）、**公历 / 农历 iOS 分段控件 + 每年重复**（实时显示距今天数）、倒数本选择、提醒开关、置顶开关、封面图片与详情页背景设置；**日期选择为自制 iOS 滚轮弹层**（年 / 月 / 日三列，吸附滚动、实时星期预览、月份天数自动收拢）
- **图片来源三通道**：拍照（FileProvider）/ 系统相册（Photo Picker）/ 文件（DocumentsUI，绕开部分 ROM 相册的裁剪劫持），另有「恢复默认」移除图片；图片复制为应用私有副本，与原图脱钩；取消编辑或保存后自动清理草稿图片，不再残留
- **详情**：单页完整展示（事件名做标题，壁纸按钮收进顶栏，无隐藏的收起/展开两态）；整页背景壁纸（带压暗遮罩）；里程碑卡 + 进度条；**小记**（随时可编辑可删除、最新在上、草稿按事件隔离）；分享卡片、封存、彻底删除（iOS 式确认弹窗，红色破坏性按钮）
- **极简模式**：设置页开关。开启后首页变纯列表（名称 + 日期 + 大号天数，分组展示），编辑页只留 名称/日期/倒数本/置顶，详情页只留倒数卡与操作
- **归档 Archive**：从首页右上角进入；归档事件冻结只读，可恢复或彻底删除
- **设置 Settings**：iOS 分组内嵌列表（圆角方形图标 + 细分隔线 + chevron）；8 套清冷配色预设（中性灰底 × 单一高饱和点缀色，选中描边圆点）+ **自定义点缀色**（色相/饱和度滑杆弹层实时预览）、浅色 / 深色 / 跟随系统（滑动分段控件）、极简模式、排序方式、倒数本管理、**常驻通知**（自定义小图标，通知栏常驻显示置顶倒数卡，跨午夜自动刷新）、触感反馈、数据备份（JSON 分享，已修复）
- **动效**：页面切换按进栈 / 出栈方向平移 + 淡入淡出，Tab 切换交叉淡化，FAB 按压缩放 + 投影，进度环入场展开，chips / 分段控件颜色与滑块动画
- **图标**：自适应启动器图标（银灰渐变底 + 草帽女孩插画前景 + 单色水滴图层，源自 `girl-a.ico`）与通知小图标
- 底部导航仅「首页 / 设置」两个 tab（新建按钮只在首页显示）；旧版数据自动迁移：旧分类 → 倒数本，旧「心愿与备忘」→ 第一条小记，旧 pinned/优先级 → 置顶

## 构建与运行

```bash
set JAVA_HOME=C:\Users\ranly\scoop\apps\openjdk21\current
gradlew.bat assembleDebug
```

农历转换基于系统 ICU4J（`android.icu.util.ChineseCalendar`），锚点测试在 `app/src/androidTest`，可执行 `gradlew.bat connectedDebugAndroidTest` 验证（需已启动的模拟器）。

或用 Android Studio 打开本文件夹直接运行。编译 SDK 为 Android 36，最低支持 Android 8.0（API 26）。

### 本机测试模拟器

系统镜像（Android 37.1 x86_64）已注册到 SDK，并创建了名为 `SereinTest` 的 AVD（Pixel 6 规格），可用下面命令启动：

```bash
emulator -avd SereinTest
```

安装调试包：`adb install app\build\outputs\apk\debug\app-debug.apk`。

注意：该模拟器镜像存在平台缺陷，`adb shell pm grant` 无法授予 `POST_NOTIFICATIONS`，验证常驻通知需在系统设置里手动允许。

> Acid Lime 设计系统（高对比 Web3 / FinTech × 轻 Neo-Brutalism） · v1.5.1
> 代码对应：`app/src/main/java/com/serein/day/Theme.kt`（色彩令牌）、`Common.kt`（组件与线稿插画）

## 0. 风格 DNA

Off-white 背景 + Black Card + Acid Lime + Oversized Typography + Rounded Cards + Line Illustration。
关键词：Cash App UI · Acid Lime Web Design · Web3 Wallet UI · Refined Neo Brutalism · High Contrast Fintech UI。

**信息架构（v1.5.2）**：无底部导航。品牌头部（Serein Day + 倒数本筛选胶囊 + 设置圆钮，副标题「今天是 yyyy-MM-dd 星期X」）→ 黑色 Hero 大卡 → 白卡列表（置顶行带马卡龙图标圆，普通行纯文字）→ 底部青柠 CTA。倒数本筛选为头部胶囊弹层；归档入口在设置页；详情页编辑入口为右上角青柠圆形铅笔钮；每个事件支持挂「小倒数日」子节点。设置、归档、详情、编辑均为推入页面（iOS push/pop 转场）。

## 1. 设计原则

1. **极端对比**：Off-white（浅色）/ 纯黑（深色）中性底，卡片用纯白（浅色）/ 炭灰（深色）；黑色大卡（Hero、详情里程碑）在两套主题下恒为近黑墨色，是全 app 的视觉锚点。
2. **青柠即能量**：唯一的荧光青柠 accent 承担全部「能量语义」——CTA、大号天数、进度、火苗灯锥、选中胶囊；`onAccent` 一律近黑，保证黑字压荧光底的高对比。
3. **墨色为骨架**：primary = 近黑墨色（深色下翻转银白），只做静态强调：标题文字、列表大数字、选中 chip、次级按钮底。
4. **超大字号**：天数用 Black 字重 + 负字距放大到 86sp（首页 Hero）/ 40sp（详情环心），数字即版面主角。
5. **线稿插画**：黑卡右侧按倒数本类别绘制白色线稿（行李箱 / 蛋糕 / 台灯书堆 / 日历页），青柠只做小面积点睛（行李牌、火苗、灯锥、星）。
6. **圆角与胶囊**：大卡 30dp → 分组容器 24dp → 小卡 22dp → 弹窗 18dp → 按钮/标签一律全圆角胶囊；不用直角盒子。

## 7. 动效标注

| 动效 | 参数 |
|---|---|
| 页面进栈/出栈 | 临界阻尼弹簧 `damping 1.0 / stiffness 280`，新页整幅滑入、旧页 −1/4 视差 |
| 按压缩放 | 按下 `1600` 即时缩放（卡片 0.98 / 行 0.97 / CTA 0.97），松开 `480` 弹回 |
| 进度环/进度条入场 | 从 0 弹簧展开 `stiffness 160` |
| Tab 切换 | Crossfade 200ms |
| 颜色状态切换 | `stiffness 300` 弹簧（chip、分段滑块、模式胶囊） |
| 无障碍 | 系统关闭动画时全部降级为即时切换（`rememberReducedMotion`） |
